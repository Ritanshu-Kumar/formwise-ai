# FormWise AI

AI-powered form creation and feedback analytics platform.

## Overview

FormWise AI allows users to create custom forms, collect responses, and
generate AI-powered insights from submitted feedback.

## Planned Features

- Form builder
- Public forms
- Response collection
- AI summarization
- Sentiment analysis
- Topic extraction
- Response categorization
- Analytics dashboard
- AI-generated insights

## Architecture

Next.js → FastAPI → PostgreSQL → AI Analysis Service

Under active development
